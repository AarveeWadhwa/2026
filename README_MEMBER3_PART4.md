# BidPilot AI — Member 3 Part 4

Adds a portfolio-level report generator that consumes the JSON emitted by Member 3 Part 3 and writes JSON, CSV, and Markdown outputs.

See `docs/member3_part4.md` for details and the run command.

Run tests with:

```bash
python3 -m unittest tests.test_bid_portfolio_report -v
```

This is a reporting layer over provided data, not live tender monitoring or a legal decision system.
